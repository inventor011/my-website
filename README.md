# ayush — personal site

A minimal personal website for collecting artifacts (interactive HTML experiments), images, and a short bio.

## Structure

```
index.html      — single-page site
style.css       — styles (dark theme, no frameworks)
artifacts/      — drop HTML artifacts here, link from index
images/         — drop images here, reference from gallery
```

## Usage

Open `index.html` in a browser. No build step, no dependencies.
